# Oracle Frontend Layout

## Pages
- **Login**
  - Magic.link authentication form
- **Creator Dashboard**
  - Recent videos grid
  - Quick stats (followers, revenue)
- **Wallet**
  - Stripe balance overview
  - Payout history table
- **Video Generator**
  - Text input for caption
  - Background selector
  - Generate button and preview
- **Marketplace** (Phase 2)
  - Creator cards
  - Purchase buttons

## Components
- Navbar with user avatar and links
- Sidebar for navigation on desktop
- Responsive cards for videos and payments
